## 1. 概要

**Tidslinjal** は、地理的に分散したチーム向けの協働型Webベースオペレーションタイムラインツールです。作戦計画、イベント調整、状況認識のための共有タイムラインを提供し、軍事演習やサイバーインシデント対応、危機管理をサポートします。

主な機能:
- 複数ユーザーによる共有タイムラインとロールベースアクセス
- 承認ワークフロー付きイベントライフサイクル管理
- アクティビティストリーム分離のための名前付きレイヤー
- STARTEX/ENDEXとシミュレーション「Day N / H+N」時刻による演習サポート
- Server-Sent Events (SSE) によるリアルタイムアラーム通知
- 日記モジュール（リッチテキストエディタ、タグ、添付ファイル）
- スプレッドシートツール（数式、フィルター、エクスポート対応）
- 19言語対応のi18nサポート

## 2. はじめに

### ログイン

ブラウザで Tidslinjal のURLにアクセスし、ユーザー名とパスワードでログインします。OIDCが設定されている場合は、「SSOでログイン」ボタンを使用できます。

### セルフ登録

有効な場合、ログインページの「登録」リンクから新規アカウントを作成できます。管理者による承認が必要な場合があります。

### パスワードリセット

「パスワードを忘れた」リンクをクリックし、ユーザー名を入力します。メールが設定されている場合、リセットリンクが送信されます。

## 3. インターフェース

画面は以下の部分で構成されています:

| エリア | 説明 |
|---|---|
| **ヘッダー** | ロゴ、時計、検索、言語フラグ、ユーザーメニュー |
| **ツールバー** | 表示範囲、解像度、レイアウト切替、ツールボタン |
| **サイドバー** | タブ式パネル: 凡例、ユーザー、設定、統合、ツール、情報管理 |
| **タイムライングリッド** | 列=日、行=時間帯、イベントブロック表示 |
| **ティッカー** | 画面下部のスクロール型ナラティブティッカー |

---

## 4. タイムラインのナビゲーション

### 日付ナビゲーション

- **矢印キー**: 左右で前日・翌日に移動
- **「今日」ボタン**: 本日にジャンプ
- **日付ピッカー**: 特定の日付に直接移動

### 表示範囲

日、2日、3日、4日、5日、週、2週、3週、月から選択可能です。

### 解像度

10分、15分、1時間、1日のスロットサイズから選択できます。

### ズーム

時間列をドラッグしてスロットの高さを拡大・縮小できます。ダブルクリックでリセットします。

## 5. イベント

### イベントの作成

タイムライングリッドのセルをクリックするか、**+** ボタンをクリックします。以下の情報を入力:

- タイトル（必須）と説明
- イベントタイプとカスタムカラー
- 開始時刻と終了時刻
- 担当者と招待者
- レイヤー割り当て
- ファイル添付（最大25MB）
- アラーム設定

### イベントタイプ

| アイコン | タイプ | 説明 |
|---|---|---|
| — | **イベント** | 一般的な出来事 |
| ⚡ | **インスタント** | 時点マーカー（終了時刻なし）|
| 🤝 | **ミーティング** | 予定されたミーティング |
| 🏢 | **対面ミーティング** | 場所指定の対面ミーティング |
| ⚖️ | **意思決定** | 決定ポイント |
| ⏰ | **締切** | 期限 |
| — | **アクティビティ** | 計画された作業 |
| 🔄 | **繰り返し** | 定期的なアクティビティ |
| 📊 | **レポート** | 報告・ブリーフィング |
| 📌 | **割当タスク** | 委任されたタスク |
| 🧍 | **スタンドアップ** | 短時間のデイリーミーティング |
| 🔌 | **外部イベント** | 統合システムからの外部メッセージ |

### インスタントイベント

タイプを「インスタント」に設定すると、終了時刻のない時点マーカーとして表示されます。

### 終日イベント

「終日」チェックボックスをオンにすると、特定の時刻なしで終日エリアに表示されます。

## 7. コメント

イベントにコメントを追加して、議論や更新情報を記録できます。コメントは時系列で表示され、すべてのユーザーに表示されます。

## 8. レイヤー

レイヤーはアクティビティストリームを分離するために使用します。

### レイヤーの作成

チームリーダー以上の権限で新しいレイヤーを作成できます。名前、説明、色、可視性（プライベート/グループ/パブリック）を設定します。

### 可視性

| レベル | アクセス |
|---|---|
| **プライベート** | オーナーのみ |
| **グループ** | オーナー + 選択したグループのメンバー |
| **パブリック** | 全ユーザー |

---

## 9. アラームと通知

### アラームの設定

イベント作成・編集時に、開始前の分数を指定してアラームを設定できます。

### アラーム通知

アラームが発火すると、音声通知とブラウザ通知が表示されます。ミーティングURLが設定されている場合、「ミーティングに参加」ボタンが表示されます。

### Webhook通知

設定でWebhook URLを設定すると、アラーム発火時にJSON POSTが送信されます。Mattermost、Slack、汎用形式に対応しています。

---

## 10. 演習とシミュレーション時刻

### 設定（管理者のみ）

1. 演習名を入力
2. STARTEX（開始時刻）を設定
3. ENDEX（終了時刻）を設定（任意）
4. シミュレーション時刻表示を有効化

### シミュレーション時刻

有効にすると、タイムラインに「H+N」形式の経過時間と「Day N」の日数が表示されます。

### タイムラインフリーズ

進行を一時停止して演習レビューを行えます。

---

## 11. 演習フェーズ

タイムラインにカラー帯でフェーズを表示できます（例：準備、実行、事後分析）。フェーズはドラッグで移動・リサイズ可能です。

---

## 12. タイムスロットロック

管理者はタイムスロットをロックして、イベントの作成・移動を防止できます。ロックされたスロットは斜線パターンで表示されます。

## 15. エクスポートとレポート

イベントデータを以下の形式でエクスポートできます:
- CSV、XLSX、ODS、JSON、XML、Markdown、RTF、PDF

レポートモジュールでSITREP、活動レポートなどを生成できます。日付範囲とフィルターを指定して内容をカスタマイズします。

## 17. 時計、カウントダウン、タイマー

### マルチタイムゾーン時計

ヘッダーの **+** ボタンで追加のタイムゾーン時計を追加できます。ラベルとタイムゾーンを選択します。

### VCRセブンセグメント表示

デジタル、アナログ、VCR表示モードを選択できます。

### カウントダウンタイマー

イベント開始までのカウントダウンを設定できます。

## 18. 意思決定ログ

### 意思決定の作成

タイトル、テキスト、理由を入力して意思決定を記録します。シーケンス番号が自動割当されます。

### 意思決定ステータス

記録済み → 承認済み / 却下 / エスカレーション

## 19. ログブック

ログブックは全イベント、意思決定、監査ログのタイムスタンプ付きフィードです。カテゴリー、日付範囲、テキストでフィルタリングできます。

### リソースタイプ

部屋、建物、ITサービス、データセンター、車両、機器、機能（ケイパビリティ）を管理できます。

### リソースの作成

サイドバーのリソースタブから追加します。名前、タイプ、説明、場所を設定します。

## 23. 統合とコネクター

### API キー

外部ツールがセッションなしで Tidslinjal にアクセスするためのAPIキーを作成できます。`Authorization: Bearer <key>` ヘッダーを使用します。

### コネクター

GitHub/GitLab、Jira、STIX/TAXII、Google Calendar などの外部システムと連携できます。

### Webhook

アラーム発火時やイベント変更時にHTTP POSTを外部URLに送信します。

## 26. トラブルシューティング

### ログインできない

- ユーザー名・パスワードを確認
- アカウントがブロックされていないか確認
- OIDC設定を確認

### イベントが表示されない

- レイヤーの可視性を確認
- 日付範囲を確認
- イベントタイプフィルターを確認

## 機能（ケイパビリティ）

**機能**（🎯 リソース内）は追跡可能なオペレーション機能を表します:
- **名前** — 機能の名前
- **ゾーン** — 地理的/エリア配置（任意）
- **説明** — 自由記述
- **所有権** — 機能の所有者/運用者
- **オーナー** — 機能の所有者
- **ステータス** — 稼働中、劣化、停止、不明

機能は**リアクティブオブジェクト**です: キーテレインボードのエントリにリンクされると、名前、ゾーン、ステータス、所有権、オーナーの変更が自動的に反映されます。

## キーテレインボードの改善 (v8.3.0)

- **優先度チェックボックスフィルター** — 0〜10の値
- **ステータスチェックボックスフィルター** — 稼働中/劣化/停止/不明
- **トレンドチェックボックスフィルター** — 改善/安定/悪化
