## 1. Огляд

**Tidslinjal** — це колаборативний веб-інструмент оперативної часової шкали для географічно розподілених команд. Він забезпечує спільну візуальну хронологію подій для планування операцій, координації та ситуаційної обізнаності — включно з підтримкою військових навчань і навчань з надзвичайних ситуацій із синтетичним часом.

Основні можливості:
- Спільна часова шкала для кількох користувачів із рольовим доступом
- Управління життєвим циклом подій із процесом затвердження
- Іменовані шари для розділення потоків активностей
- Підтримка навчань із STARTEX/ENDEX та синтетичним часом "День N / T+T"
- Сповіщення про сигнали в реальному часі через Server-Sent Events
- Експорт у ICS, JSON та CSV
- DTG (Date-Time Group) — військовий формат дати
- Режим високого контрасту та палітри для людей із порушенням кольорового зору
- Підтримка фінської (Suomi) мови
- Управління довідковими документами з контрольними сумами
- Передустановки робочого простору

## 2. Початок роботи

### Вхід у систему

Перейдіть за адресою `http://<сервер>:<порт>` (за замовчуванням: `http://localhost:8080`).

```
┌─────────────────────────────────┐
│          TIDSLINJAL             │
│                                 │
│  Ім'я користувача: [admin    ] │
│  Пароль:           [••••••••••] │
│                                 │
│           [ Увійти ]            │
└─────────────────────────────────┘
```

Облікові дані за замовчуванням: `admin` / `admin`

> **Примітка безпеки:** Негайно змініть пароль адміністратора після першого входу за допомогою кнопки 🔑 у верхньому правому куті.

### Самостійна реєстрація

Якщо адміністратор увімкнув самостійну реєстрацію, на сторінці входу відображається посилання **"Немає облікового запису? Зареєструватися"**. Є чотири режими реєстрації:

| Режим | Опис |
|---|---|
| **Відкрита** | Будь-хто може зареєструватися; обліковий запис активується одразу |
| **З перевіркою** | Будь-хто може зареєструватися; адміністратор повинен схвалити обліковий запис перед входом |
| **Загальне запрошення** | Реєстрація потребує спільного коду запрошення, наданого адміністратором |
| **Персональне запрошення** | Реєстрація потребує персонального одноразового коду, згенерованого адміністратором для кожного користувача |

### Відновлення пароля

Якщо ви зареєстрували електронну адресу у своєму профілі:

1. Натисніть **Забули пароль?** на сторінці входу
2. Введіть ваше ім'я користувача або електронну адресу
3. Буде згенеровано токен відновлення (відображається на екрані, якщо поштовий сервер не налаштовано)
4. Натисніть **Відновити пароль**, вставте токен і виберіть новий пароль

### Зміна пароля

Натисніть кнопку **🔑** у заголовку. Введіть поточний пароль, а потім новий пароль двічі.

## 4. Навігація часовою шкалою

### Навігація за датою

| Елемент керування | Дія |
|---|---|
| Кнопки **‹** / **›** | Крок назад / вперед на один інтервал відображення |
| Кнопка **Сьогодні** | Перейти до сьогодні |
| Кнопка **⏱** | Прокрутити сітку до поточного часу |

### Інтервал відображення

Використовуйте випадаюче меню **Вигляд** на панелі інструментів:

```
Вигляд: [День ▼]
         День
         2 Дні
         3 Дні
         4 Дні
       ▶ Тиждень
         Місяць
         2 Місяці
         3 Місяці
```

### Роздільність (висота слота)

Використовуйте випадаюче меню **Роздільність**:

```
Роздільність: [Година ▼]
               10 хв
               15 хв
             ▶ Година
               День
```

### Масштабування

**Перетягування для масштабування** — натисніть і перетягніть вгору/вниз на стовпці часу (лівий край), щоб збільшити або зменшити висоту слота. Перетягніть **вгору** для збільшення, **вниз** для зменшення.

**Подвійний клік** на стовпці часу для скидання масштабу до 1×.

Клавіатура: **+** / **-** для масштабування кроками.

### Горизонтальне панорамування

Натисніть середню кнопку миші та перетягніть на області часової шкали для панорамування вліво/вправо.

## 5. Події

### Створення події

Натисніть на порожню клітинку в сітці часової шкали або натисніть **+ Додати подію** у заголовку.

```
┌─────────────────────── Додати подію ──────────────────────────────┐
│ Назва *  [                                                      ]   │
│                                                                     │
│ Тип      [Активність      ▼]   Колір  [■]                          │
│                                                                     │
│ Початок *[2025-06-01T10:00]    Кінець [2025-06-01T11:00]           │
│                                                                     │
│ Шар      [Основна лінія   ▼]  Статус [Запланована      ▼]         │
│                                                                     │
│ Опис                                                                │
│ [                                                                ]  │
│                                                                     │
│ Учасники  [—  ▼]   ☐ Подія на весь день (без конкретного часу)      │
│                                                                     │
│ ☐ Повторювана    Шаблон [Щотижня ▼]                                │
│ Дата закінчення  [               ]                                  │
│                                                                     │
│ Вкладення 📎 [Обрати файл]                                          │
│                                                                     │
│              [Скасувати]   [Зберегти]                                │
└─────────────────────────────────────────────────────────────────────┘
```

### Типи подій

Кожен тип події має кольоровий блок та іконку, яка відображається **ліворуч** від назви події.

| Іконка | Тип | Колір | Примітки |
|---|---|---|---|
| — | **Подія** | Синій | Загальна подія |
| ⚡ | **Момент** | Помаранчевий | Одна точка в часі — без часу завершення. Відображається як маркер ◆ ромб. |
| 🤝 | **Зустріч** | Сірий | Запланована зустріч |
| 🏢 | **Очна зустріч** | Темно-помаранчевий | Очна зустріч у конкретному місці |
| ⚖️ | **Рішення** | Зелений | Точка прийняття рішення |
| ⏰ | **Дедлайн** | Червоний | Жорсткий термін |
| — | **Активність** | Зелений | Робочий блок |
| 🔄 | **Повторювана** | Фіолетовий | Шаблон для повторюваних активностей |
| 📊 | **Звітність** | Бірюзовий | Звіт або огляд |
| 📌 | **Призначене завдання** | Помаранчевий | Завдання, призначене особі або команді |
| 🧍 | **Щоденний стендап** | Блакитний | Коротка щоденна нарада зі статусом |

Іконка ↻ (ліворуч від назви) означає, що подія є частиною **повторюваної серії**. Користувацькі типи можуть мати власну emoji-іконку, встановлену через **Налаштування → Типи подій → Редагувати**.

Увімкніть/вимкніть усі іконки глобально в **Налаштування → Іконки подій**.

Користувацькі типи можуть додаватися користувачами з правами Читання/Запис+ із панелі налаштувань.

### Моментальні події

Коли **Момент** обрано як тип:
- Поле **Кінець** приховується (без тривалості)
- Подія відображається як вузький вертикальний маркер із ромбом ◆ зверху
- Не може бути налаштована як повторювана

### Подія на весь день

Позначте **Подія на весь день (без конкретного часу)** для події, що охоплює весь день:
- Поля часу початку/завершення приховуються
- Подія відображається в сірій зоні поза робочими годинами
- Повторення недоступне для подій на весь день

### Учасники

Поле **Учасники** вказує, чи залучені до активності внутрішні або зовнішні сторони:

| Значення | Мітка | Колір |
|---|---|---|
| — | немає | — |
| **Внутрішній** | `ВНУТРІШНІЙ` | Бірюзовий |
| **Зовнішній** | `ЗОВНІШНІЙ` | Червоний |

### Повторювані події

Позначте **Повторювана**, потім оберіть шаблон:

| Шаблон | Інтервал |
|---|---|
| Кожні 30 хвилин | 30 хвилин |
| Щогодини | 1 година |
| Кожні 2 / 3 / 4 години | 2 / 3 / 4 години |
| Щодня | 1 день |
| Щотижня | 7 днів |
| Щомісяця | ~1 місяць |
| Щоквартально | ~3 місяці |

### Редагування та видалення подій

Натисніть на блок події, щоб відкрити детальний вигляд. Натисніть **Редагувати** для зміни. Натисніть **Видалити** (видно для автора та адмінів) для видалення.

## 6. Робочий процес статусів подій

Кожна подія має статус, що проходить через життєвий цикл:

```
запланована ──► активна ──► відповіджена ──► завершена ──► подана
                                                              │
                                                   ┌──────────┤
                                                   ▼          ▼
                                               перевірена  відхилена
                                                              │
                                                        (потрібна причина)
```

`скасована` доступна на будь-якому етапі.

### Переходи

| Від → До | Хто може діяти |
|---|---|
| Будь-який → будь-який (окрім перевірити/відхилити) | Автор, Керівник групи+ |
| відповіджена | Кореспондент, Автор, Керівник групи+ |
| подана → перевірена | Керівник групи+ (реєструє хто і коли) |
| подана → відхилена | Керівник групи+ (потребує причину відхилення) |

### Роль кореспондента

Користувачі з роллю **Кореспондент** можуть:
- Публікувати коментарі до подій
- Встановлювати статус `відповіджена` або `завершена` (потребує затвердження Керівника групи)

## 7. Коментарі

Натисніть на блок події, щоб відкрити детальний вигляд. Прокрутіть вниз до **Коментарі**.

- Усі автентифіковані користувачі можуть читати коментарі
- Користувачі з правами Читання/Запис+ можуть публікувати коментарі
- Кореспонденти можуть публікувати коментарі; коментарі зі зміною статусу потребують затвердження
- Керівники груп+ можуть затверджувати або видаляти очікуючі коментарі

## 8. Шари

Шари — це іменовані накладки поверх основної лінії. Вони дозволяють різним командам мати окремі потоки подій зі спільним виглядом.

### Створення шару

1. Відкрийте вкладку **Шари** на бічній панелі або натисніть **🗂 Шари** на панелі інструментів
2. Натисніть **+ Новий шар**
3. Введіть назву, колір, опис, видимість і дозволи

```
┌──────── Новий шар ────────────┐
│ Назва *   [Кіберкоманда     ]  │
│ Колір     [■ #9B59B6         ]  │
│ Опис      [                  ]│
│                                │
│ Видимість [Групи         ▼]   │
│ Дозвіл   [Читання/Запис ▼]    │
│ Групи     ☐ Alpha  ☐ Bravo    │
│                                │
│         [Скасувати]  [Зберегти]│
└────────────────────────────────┘
```

### Видимість

| Налаштування | Хто бачить шар |
|---|---|
| **Приватний** | Тільки власник |
| **Групи** | Власник + учасники обраних груп |
| **Публічний** | Усі автентифіковані користувачі |

### Перемикання шарів

Натисніть **🗂 Шари** на панелі інструментів, щоб відкрити панель швидкого перемикання. Натисніть на елемент, щоб переключити його. Кілька шарів можуть бути активними одночасно — позначте прапорці для шарів, які хочете бачити.

## 9. Сигнали та сповіщення

### Встановлення сигналу

1. Натисніть на блок події, щоб відкрити детальний вигляд
2. Натисніть **🔔 Встановити сигнал**
3. Оберіть час випередження (у момент події, за 5/10/15/30 хв або за 1 годину)

### Сповіщення сигналів

Коли сигнал спрацьовує, у верхній частині екрана з'являється панель сповіщень:

```
┌──────────────────────────────────────────────────────────────────────┐
│ 🔔 Сигнал — "Огляд ENDEX" через 15 хвилин (10:45)                    │
│                    [Закрити] [📋 Переглянути подію] [✓ ACK]          │
└──────────────────────────────────────────────────────────────────────┘
```

- **Закрити** — прибирає сповіщення без підтвердження.
- **📋 Переглянути подію** — відкриває детальний вигляд події безпосередньо із сигналу.
- **✓ ACK** — підтверджує сигнал і зупиняє ескалацію.
- Кнопка **Перейти до зустрічі** — якщо подія є зустріччю з URL (Teams/Zoom), у сповіщенні відображається кнопка для прямого переходу до зустрічі.

Непідтверджені сигнали ескалюються — вони стають помаранчевими, потім пульсуючими червоними кожні 60 секунд.

### Журнал аудиту сигналів

Кожне підтвердження сигналу реєструється в **Журналі аудиту** (доступно для Керівників груп і вище). Кожен запис містить:
- Хто підтвердив сигнал (ім'я користувача та ID)
- Коли відбулося підтвердження (позначка часу)
- IP-адреса, з якої здійснювався доступ до системи в той момент

### Годинники для кількох часових поясів

Заголовок відображає основний годинник реального часу. Можна додати будь-яку кількість годинників для інших часових поясів.

**Додавання годинника:**
1. Натисніть кнопку **+** ліворуч від головного годинника в заголовку.
2. Введіть коротку мітку (наприклад, *Таллінн*, *Київ*, *Кабул*).
3. Оберіть часовий пояс IANA у випадаючому меню.
4. Натисніть **Додати**. Годинник одразу з'явиться ліворуч від головного годинника.

**Видалення годинника:** Натисніть **×** на віджеті годинника або перейдіть до **Налаштування → Формат дати/часу → Додаткові часові пояси → Видалити**.

### Webhook-сповіщення

Налаштуйте webhook-URL у **Налаштуваннях**, щоб також отримувати сповіщення сигналів через HTTP POST до Mattermost, Slack або будь-якої HTTP-точки.

### Вкладка сигналів на бічній панелі

Переглядайте та керуйте всіма активними сигналами з вкладки **Сигнали** на бічній панелі.

## 10. Навчання та синтетичний час

Для тренувальних навчань Tidslinjal підтримує режим «синтетичного часу», який замінює реальні календарні дати мітками днів/годин навчання.

### Конфігурація (тільки адмін)

1. Відкрийте вкладку **Налаштування** на бічній панелі
2. Прокрутіть вниз до **Налаштування навчання**
3. Заповніть:
   - **Назва навчання** — відображається як мітка в заголовку
   - **STARTEX** — реальна дата і час, що відповідає "День 1 T+0"
   - **ENDEX** — реальна дата і час завершення навчання
4. Позначте **Увімкнути відображення синтетичного часу**
5. Натисніть **Зберегти**

### Увімкнення синтетичного часу

Кнопка **🕐 T+** з'являється на панелі інструментів, коли режим навчання налаштовано. Натисніть, щоб перемикатися між реальним і синтетичним відображенням часу.

### Заморожування часової шкали

На панелі **Налаштування** використовуйте **Заморозити/призупинити часову шкалу**, щоб зупинити синтетичний годинник у конкретний момент. Натисніть **Відновити**, щоб зняти заморожування.

## 11. Фази навчання

Керівники груп і вищі ролі можуть визначати іменовані, кольорові блоки, що охоплюють усю часову шкалу для відображення фаз навчання.

1. Відкрийте вкладку **Фази** на бічній панелі
2. Натисніть **+ Нова фаза**
3. Введіть назву, колір, час початку, час завершення та порядок відображення (0–9)

Фази відображаються як напівпрозорі кольорові смуги вгорі сітки часової шкали.

## 12. Блокування часових слотів

Адміни та користувачі з прапорцем `може_блокувати` можуть блокувати часові інтервали для запобігання створенню подій.

1. Натисніть **🔒 Заблокувати часовий слот** у заголовку (видно для адмінів/користувачів із може_блокувати)
2. Введіть час початку, час завершення та причину

Заблоковані часові слоти відображаються як червоне штрихове накладення. Події не можуть бути створені в заблокованих часових слотах.

## 13. Ролі та дозволи

| Роль | Скорочення | Можливості |
|---|---|---|
| **Спостерігач** | `observer` | Доступ лише для читання часової шкали та подій — не може редагувати, коментувати або блокувати |
| **Читання** | `read` | Перегляд часової шкали, подій, шарів; встановлення персональних сигналів |
| **Кореспондент** | `reporter` | + Публікація коментарів; встановлення статусу відповіджена/завершена (із затвердженням) |
| **Читання/Запис** | `readwrite` | + Створення/редагування власних подій; створення типів подій та шарів |
| **Керівник групи** | `teamlead` | + Створення груп; перевірка/відхилення поданих подій; перегляд журналу аудиту; керування фазами |
| **Керівник операції** | `oplead` | + Створення/редагування/видалення подій на основній лінії |
| **Помічник штабу** | `staffofficer` | Ті самі права, що й керівник операції — альтернативне позначення для штабного персоналу |
| **Штабний офіцер** | `staffofficer_full` | Те саме, що й помічник штабу, але вимагає принаймні одне J-позначення (J1–J9) |
| **Адмін** | `admin` | Повний доступ — керування всіма користувачами, ролями, блокуваннями, налаштуваннями навчання, реєстрацією |

Прапорець `може_блокувати` може бути призначений будь-якому користувачу незалежно від ролі.

### J-позначення (роль штабного офіцера)

**Штабний офіцер** (`staffofficer_full`) вимагає принаймні одне J-позначення за стандартами NATO. Позначення ідентифікують штабну гілку:

| Код | Гілка |
|---|---|
| J1 | Особовий склад |
| J2 | Розвідка |
| J3 | Операції |
| J4 | Логістика |
| J5 | Планування |
| J6 | Зв'язок |
| J7 | Підготовка |
| J8 | Фінанси |
| J9 | Цивільно-військова співпраця |

## 17. Годинники, зворотні відліки та таймери

### Годинники часових поясів
Годинник у заголовку відображає місцевий реальний час. Натисніть **+**, щоб додати додаткові часові пояси для розподілених команд. Натисніть **⧉**, щоб від'єднати всі годинники в окреме вікно.

### Дисплей VCR із семисегментним індикатором
Годинники відображаються в ретро-стилі VCR із семисегментним індикатором. Кольори та товщину сегментів можна налаштувати.

### Зворотний відлік
Створюйте зворотні відліки, що рахують до цільового часу:
- Натисніть **+ Зворотний відлік** на панелі інструментів годинників
- Встановіть цільовий час або оберіть із часу початку/завершення події
- Зворотний відлік показує час, що залишається, з **індикатором прогресу**
- Сигнал спрацьовує, коли зворотний відлік досягає нуля
- Натисніть **ACK** для підтвердження

### Таймер
Створюйте таймери, що рахують вгору:
- Натисніть **+ Таймер** на панелі інструментів годинників
- Налаштуйте: тривалість (години/хвилини/секунди), кнопки швидкого вибору (5/10/15/30/60 хв)
- Оберіть, чи повинен таймер зупинитися або продовжити після цільового часу
- Увімкніть звуковий сигнал при досягненні мети
- Таймер показує **індикатор прогресу** з позначкою перевищення часу

### Вибір кольору
Панель інструментів годинників містить селектори кольору:
| Селектор | Керує |
|---|---|
| **BG** | Колір фону |
| **CD** | Акцентний колір зворотного відліку |
| **TM** | Акцентний колір таймера |

## 21. Картографічна проєкція
Картографічна проєкція забезпечує інтерактивний географічний вигляд зустрічей, користувачів і ресурсів.

- **Шари карти** — перемикання між OpenStreetMap, Топографічна, Супутникова та Темна
- **Накладення ресурсів** — показати/приховати приміщення, будівлі, ІТ-послуги та дата-центри
- **Пошук адреси** — геокодування адреси та масштабування до місця
- **Вибір символів** — вибір військових та оперативних картографічних символів для ресурсів і подій
- **Імпорт GeoJSON/KML** — завантаження зовнішніх географічних файлів даних
- **Підігнати все** — автоматичне масштабування для відображення всіх видимих маркерів

## 24. Шаблони
Зберігайте та повторно використовуйте набори подій, фаз, блокувань, груп і шарів:

## 25. Гарячі клавіші та дії миші

### Миша

| Дія | Результат |
|---|---|
| Клік на порожній часовий слот | Відкрити Додати подію для цього часу |
| Клік на блок події | Відкрити деталі події |
| Перетягування блоку події | Перепланувати до цільового слота |

| Перетягування середньою кнопкою на часовій шкалі | Горизонтальне панорамування |

### Клавіатура

| Клавіша | Дія |
|---|---|
| `←` / `→` | Навігація назад / вперед на один інтервал |
| `T` | Перейти до сьогодні |
| `N` | Прокрутити до поточного часу |
| `E` | Відкрити діалог Додати подію |
| `?` або `H` | Відкрити вбудовану довідку |
| `Esc` | Закрити поточне модальне вікно |
| `+` / `-` | Збільшити/зменшити масштаб висоти слота |
| `F` | Заморозити / відновити синтетичний час |

## 26. Усунення неполадок

### Не вдається увійти
- Перевірте ім'я користувача та пароль (за замовчуванням: `admin` / `admin`)
- Переконайтеся, що сервер працює: `./tidslinjal --port 8080`
- Перевірте журнал сервера на наявність помилок

### Події не відображаються
- Перевірте діапазон дат **Вигляду** — можливо, ви переглядаєте інтервал, що не включає ваші події
- Перевірте фільтр **Шарів** — натисніть 🗂 і переконайтеся, що потрібні шари активні
- Перевірте **Видимість типів подій** у Налаштуваннях — приховані типи не відображаються

### Сигнал не спрацьовує
- SSE вимагає постійного з'єднання браузера — переконайтеся, що сторінка відкрита
- Перевірте, що сповіщення браузера дозволені для сайту
- Перевірте час випередження сигналу: при 0 хв сигнал спрацьовує точно в час початку події

### Перемикання шарів не працює
- Натисніть **🗂 Шари** на панелі інструментів
- Оберіть **Основну лінію**, щоб побачити всі шари
- Або оберіть окремі шари для фільтрації

### Експорт дає порожній файл
- Переконайтеся, що в поточному інтервалі відображення є події
- Налаштуйте інтервал **Вигляду**, щоб включити бажані події

### Каталог даних недоступний для запису
- Переконайтеся, що каталог `data/` існує та доступний для запису серверним процесом
- Використовуйте `--data /шлях/до/каталогу/для/запису` або встановіть змінну середовища `DATA_DIR`

## 27. Довідки та бібліотека документів

Довідкова бібліотека дозволяє керувати документами та посиланнями, пов'язаними з операціями та навчаннями.

### Завантаження довідок

Завантажуйте довідки як файл, URL або локальний текст. Система підтримує масове завантаження (кілька файлів одночасно) та автоматичне визначення типу файлу.

### Метадані довідок

Кожна довідка має наступні метадані:

| Поле | Опис |
|---|---|
| **Назва** | Назва довідки |
| **Опис** | Короткий зміст |
| **Категорія** | Класифікація (див. нижче) |
| **Теги** | Вільні теги для пошуку |
| **Мова** | Мова документа |
| **Власник** | Відповідальна особа |
| **Розпорядник** | Особа, що підтримує документ |
| **Режим копіювання** | Спосіб зберігання документа (див. нижче) |

### Категорії

| Категорія |
|---|
| Посібник |
| SOP |
| Політика |
| Карта |
| Довідка |
| Контрольний список |
| FAQ |
| Ціль |
| Інше |

### Режими копіювання

| Режим | Опис |
|---|---|
| **Центральна копія** | Файл зберігається централізовано на сервері |
| **Локальна копія** | Файл зберігається локально у користувача |
| **Посилання** | Без копії — лише посилання на оригінальне джерело |

### Редагування метаданих довідки

Натисніть на довідку, щоб відкрити детальний вигляд. Натисніть **Редагувати**, щоб змінити метадані.

### Криптографічні контрольні суми

Система автоматично обчислює криптографічні контрольні суми для завантажених файлів:

| Алгоритм |
|---|
| MD5 |
| SHA-1 |
| SHA-256 |
| SHA-512 |

Натисніть **Показати контрольні суми**, щоб відкрити вікно контрольних сум з усіма обчисленими значеннями.

### Пошук та фільтрація

Використовуйте поле пошуку та фільтри категорій для знаходження довідок. Фільтруйте за категорією, тегами та вільним текстом.

## 28. Доступність

### Режим високого контрасту

Режим високого контрасту може бути накладений на будь-яку тему та підвищує видимість:
- Ліній сітки
- Часових маркерів
- Смуг фаз
- Накладень блокувань
- Виділених подій

Увімкніть через **Налаштування → Тема та відображення → Режим високого контрасту**.

### Палітри для порушення кольорового зору

Три палітри для порушення кольорового зору доступні:

| Палітра | Тип |
|---|---|
| **Протанопія** | Червоно-зелена колірна сліпота |
| **Дейтеранопія** | Зелено-червона колірна сліпота |
| **Тританопія** | Синьо-жовта колірна сліпота |

Увімкніть через **Налаштування → Тема та відображення → Палітра для порушення кольорового зору**.

Режим високого контрасту та палітри для порушення кольорового зору можуть бути увімкнені одночасно.

## 29. Передустановки робочого простору

Зберігайте та відновлюйте іменовані передустановки робочого простору для швидкого доступу до ваших найчастіших виглядів.

### Збереження передустановки

Передустановка зберігає наступні налаштування:
- Вигляд (сітка, список, журнал, рішення, карта, звіти)
- Інтервал
- Роздільність
- Рівень масштабування
- Приховані шари
- Вкладка бічної панелі

### Завантаження передустановки

Натисніть на збережену передустановку, щоб негайно застосувати всі збережені налаштування одним кліком.

### Видалення передустановки

Натисніть **Видалити** поруч із передустановкою, щоб видалити її.
