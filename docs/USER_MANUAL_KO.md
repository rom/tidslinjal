## 1. 개요

**Tidslinjal**은 지리적으로 분산된 팀을 위한 협업 기반 웹 운영 타임라인 도구입니다. 작전 계획, 이벤트 조정, 상황 인식을 위한 공유 타임라인을 제공하며 군사 훈련, 사이버 사고 대응, 위기 관리를 지원합니다.

주요 기능:
- 다중 사용자 공유 타임라인 및 역할 기반 접근 제어
- 승인 워크플로우가 포함된 이벤트 라이프사이클 관리
- 활동 스트림 분리를 위한 이름 지정 레이어
- STARTEX/ENDEX 및 시뮬레이션 "Day N / H+N" 시간을 통한 훈련 지원
- Server-Sent Events (SSE)를 통한 실시간 알람 알림
- 일기 모듈 (리치 텍스트 편집기, 태그, 첨부 파일)
- 스프레드시트 도구 (수식, 필터, 내보내기 지원)
- 19개 언어 i18n 지원

## 2. 시작하기

### 로그인

브라우저에서 Tidslinjal URL에 접속하여 사용자명과 비밀번호로 로그인합니다. OIDC가 설정된 경우 "SSO로 로그인" 버튼을 사용할 수 있습니다.

### 자가 등록

활성화된 경우 로그인 페이지의 "등록" 링크로 새 계정을 만들 수 있습니다. 관리자 승인이 필요할 수 있습니다.

### 비밀번호 재설정

"비밀번호 분실" 링크를 클릭하고 사용자명을 입력합니다. 이메일이 설정된 경우 재설정 링크가 전송됩니다.

## 4. 타임라인 탐색

### 날짜 탐색

- **화살표 키**: 좌우로 이전/다음 날 이동
- **"오늘" 버튼**: 오늘로 이동
- **날짜 선택기**: 특정 날짜로 직접 이동

### 표시 범위

일, 2일, 3일, 4일, 5일, 주, 2주, 3주, 월에서 선택할 수 있습니다.

### 해상도

10분, 15분, 1시간, 1일 슬롯 크기에서 선택할 수 있습니다.

### 줌

시간 열을 드래그하여 슬롯 높이를 확대/축소합니다. 더블클릭으로 초기화합니다.

## 5. 이벤트

### 이벤트 생성

타임라인 그리드의 셀을 클릭하거나 **+** 버튼을 클릭합니다. 다음 정보를 입력합니다:

- 제목(필수)과 설명
- 이벤트 유형과 사용자 정의 색상
- 시작 시간과 종료 시간
- 담당자와 초대자
- 레이어 할당
- 파일 첨부 (최대 25MB)
- 알람 설정

### 이벤트 유형

| 아이콘 | 유형 | 설명 |
|---|---|---|
| — | **이벤트** | 일반적인 사건 |
| ⚡ | **인스턴트** | 시점 마커 (종료 시간 없음) |
| 🤝 | **미팅** | 예정된 미팅 |
| 🏢 | **대면 미팅** | 장소 지정 대면 미팅 |
| ⚖️ | **의사결정** | 결정 포인트 |
| ⏰ | **마감** | 기한 |
| — | **활동** | 계획된 작업 |
| 🔄 | **반복** | 정기적인 활동 |
| 📊 | **보고** | 보고/브리핑 |
| 📌 | **할당 작업** | 위임된 작업 |
| 🧍 | **스탠드업** | 짧은 일일 미팅 |
| 🔌 | **외부 이벤트** | 통합 시스템의 외부 메시지 |

### 인스턴트 이벤트

유형을 "인스턴트"로 설정하면 종료 시간이 없는 시점 마커로 표시됩니다.

### 종일 이벤트

"종일" 체크박스를 선택하면 특정 시간 없이 종일 영역에 표시됩니다.

## 7. 댓글

이벤트에 댓글을 추가하여 토론과 업데이트 정보를 기록할 수 있습니다. 댓글은 시간순으로 표시되며 모든 사용자에게 표시됩니다.

---

## 8. 레이어

레이어는 활동 스트림을 분리하는 데 사용됩니다.

### 레이어 생성

팀 리더 이상의 권한으로 새 레이어를 만들 수 있습니다. 이름, 설명, 색상, 가시성 (비공개/그룹/공개)을 설정합니다.

### 가시성

| 수준 | 접근 |
|---|---|
| **비공개** | 소유자만 |
| **그룹** | 소유자 + 선택한 그룹 멤버 |
| **공개** | 모든 사용자 |

---

## 9. 알람 및 알림

### 알람 설정

이벤트 생성/편집 시 시작 전 분 수를 지정하여 알람을 설정할 수 있습니다.

### 알람 알림

알람이 발생하면 소리 알림과 브라우저 알림이 표시됩니다. 미팅 URL이 설정된 경우 "미팅 참가" 버튼이 표시됩니다.

### Webhook 알림

설정에서 Webhook URL을 설정하면 알람 발생 시 JSON POST가 전송됩니다. Mattermost, Slack, 일반 형식을 지원합니다.

---

## 10. 훈련 및 시뮬레이션 시간

### 설정 (관리자 전용)

1. 훈련 이름 입력
2. STARTEX (시작 시간) 설정
3. ENDEX (종료 시간) 설정 (선택 사항)
4. 시뮬레이션 시간 표시 활성화

### 시뮬레이션 시간

활성화하면 타임라인에 "H+N" 형식의 경과 시간과 "Day N" 일수가 표시됩니다.

### 타임라인 동결

진행을 일시 중지하여 훈련 검토를 수행할 수 있습니다.

---

## 11. 훈련 단계

타임라인에 색상 띠로 단계를 표시할 수 있습니다 (예: 준비, 실행, 사후 분석). 단계는 드래그로 이동/크기 조정이 가능합니다.

---

## 12. 타임슬롯 잠금

관리자는 타임슬롯을 잠가 이벤트 생성/이동을 방지할 수 있습니다. 잠긴 슬롯은 빗금 패턴으로 표시됩니다.

## 15. 내보내기 및 보고서

### 내보내기

이벤트 데이터를 다음 형식으로 내보낼 수 있습니다:
- CSV, XLSX, ODS, JSON, XML, Markdown, RTF, PDF

### 보고서

보고서 모듈에서 SITREP, 활동 보고서 등을 생성할 수 있습니다. 날짜 범위와 필터를 지정하여 내용을 사용자 정의합니다.

- 등록 설정 (자가 등록 켜기/끄기)

## 17. 시계, 카운트다운, 타이머

이벤트 시작까지의 카운트다운을 설정할 수 있습니다.

## 23. 통합 및 커넥터

### API 키

외부 도구가 세션 없이 Tidslinjal에 접근하기 위한 API 키를 생성할 수 있습니다. `Authorization: Bearer <key>` 헤더를 사용합니다.

### 커넥터

GitHub/GitLab, Jira, STIX/TAXII, Google Calendar 등 외부 시스템과 연동할 수 있습니다.

### Webhook

알람 발생 시나 이벤트 변경 시 HTTP POST를 외부 URL로 전송합니다.

## 기능 (케이퍼빌리티)

**기능** (🎯 리소스 내)은 추적 가능한 운영 기능을 나타냅니다:
- **이름** — 기능의 이름
- **존** — 지리적/영역 배치 (선택 사항)
- **설명** — 자유 기술
- **소유권** — 기능의 소유자/운영자
- **오너** — 기능의 소유자
- **상태** — 가동 중, 성능 저하, 중단, 알 수 없음

기능은 **반응형 객체**입니다: 키 테레인 보드 항목에 연결되면 이름, 존, 상태, 소유권, 오너 변경이 자동으로 반영됩니다.

---

## 키 테레인 보드 개선 (v8.3.0)

- **오너 열** — 연결된 기능의 오너 표시; 기본적으로 숨김; 정렬 가능
- **기능의 오너 필드** — 기능 양식의 새 필드
- **기능 체크박스 필터** — 모든 기능 이름의 체크박스
- **우선순위 체크박스 필터** — 0~10 값
- **상태 체크박스 필터** — 가동 중/성능 저하/중단/알 수 없음
- **트렌드 체크박스 필터** — 개선/안정/악화
