Working with Events

Click any active time slot to open the Add Event dialog. Fill in title, type, times, and optionally a layer and status.

  • When you change the Start time, End time automatically adjusts to Start + 1 hour.
  • Drag an event block to a new slot to reschedule it.
  • Click an event block to open its Detail view.
  • From the detail view you can edit, delete, set an alarm, or change the status.
  • A 📎 icon on a block means one or more files are attached.
  • A ↻ icon means the event is recurring.
  • A ✎ icon means the event has been edited since creation.
  • Overlapping events in the same day column appear side by side.

Layers

Layers are named overlays on top of the master timeline. Each has a color, a visibility setting (Private / Groups / Public), and optional group write access.

  • Toggle layers on/off using the 🗂 Layers toolbar button.
  • When no specific layers are selected (default), all layers are visible.
  • Select specific layers in the popover to show only those.
  • Master timeline events are always shown.

Alarms

Open any event detail and click 🔔 Set Alarm. Choose how far in advance to be notified.

  • Alarms appear as notification pop-ups and in the Alarms sidebar tab.
  • Each alarm must be ACKnowledged. Un-ACK'd alarms escalate: orange after 60 s, pulsing red every further 60 s until the event time passes.
  • If a webhook URL is configured, alarms also trigger a webhook POST.

Synthetic Exercise Time

Admins can define an Exercise Epoch — the real datetime that maps to Day 1 T+0. Once enabled, users click the 🕐 T+ button in the toolbar to toggle exercise day headers (Day -1, Day 0, Day 1 …).

In synthetic time mode, the current-time red line shows an H+N label indicating hours since the exercise epoch. The timeline can also be frozen/paused to stop progression for planning.

Exercise Phases (Team Lead+) appear as color-coded semi-transparent overlays on the timeline. Up to 10 phases can be defined under the Phases sidebar tab.

Configure under Settings → Exercise Settings (Admin only).

Webhook Notifications

Each user can configure a personal webhook URL under Settings → Notifications / Webhook. When an alarm fires, a HTTP POST is sent to the URL.

  • Mattermost / Slack: sends {"text":"..."}
  • Generic: sends structured JSON {"message":"...","event_id":...}
  • Use the Test button to verify the connection.
